# Comparison operators for LazyColumn

Enables logical comparisons (`>`, `<`, `>=`, `<=`, `==`, `!=`) on a
`LazyColumn`, comparing against its scaled values.

## Usage

``` r
# S4 method for class 'LazyColumn,numeric'
Compare(e1, e2)
```

## Arguments

- e1:

  A `LazyColumn` or numeric.

- e2:

  A `LazyColumn` or numeric.

## Value

A logical vector.
