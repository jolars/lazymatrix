# Citing LazyMatrix

If you use LazyMatrix in your research, please cite the release you used.
Select that release in the [Zenodo
archive](https://doi.org/10.5281/zenodo.23666450) and export its citation. To
cite LazyMatrix generally, use the concept DOI `10.5281/zenodo.23666450`.

Machine-readable metadata is available in [CITATION.cff](https://github.com/jolars/lazymatrix/blob/main/CITATION.cff).

Python and Rust releases are versioned independently. Select the archive that
corresponds to the package and version you used.
